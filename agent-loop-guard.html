Engineering case study

Agent Loop Guard

A local safety, permissions, observability, benchmarking, sandbox, planning, and reproduction platform for coding agents. Built from multiple technical specifications and shipped as an open-source Python package plus a VS Code extension.

Source code PyPI package Documentation

01 / Problem

Coding agents can fail in expensive, repetitive, and hard-to-explain ways.

A useful safety layer has to do more than stop identical requests. It needs to understand repeated tool calls, control dangerous MCP actions, preserve a privacy-aware audit trail, compare configurations, and isolate risky code execution.

The challenge was turning five large technical briefs into one coherent project that a single developer could maintain and another developer could install locally.

02 / Constraints

Local-first, open source, and realistic for a student project.

No hosted service

SQLite, local HTTP endpoints, local approvals, and no product telemetry.

Privacy by default

Metadata-first event logging, redaction, and no chain-of-thought storage.

One repository

Shared platform contracts with separate Guard, MCP, Replay, Benchmark, and Sandbox modules.

Honest security scope

Docker isolation is documented as a technical preview, not a certified security boundary.

03 / System

A shared event model connects every module.

Requests, tool calls, policy decisions, commands, file changes, and benchmark results use a consistent event envelope. This lets the system explain not only that a run failed, but which action caused it and what happened next.

Loop Guard

Detects exact requests, repeated tool calls, recurring errors, and repeated sequences.

MCP Firewall

Applies allow, deny, confirm, transform, rate-limit, and shadow-deny policies.

Replay

Stores redacted traces, spans, durations, costs, failure tags, and run comparisons.

Benchmark Lab

Runs a versioned task dataset with deterministic scoring and regression checks.

Sandbox

Uses disposable Docker workspaces with resource limits, diff preview, apply, and discard.

Agent Playground

Runs deterministic failures through the real Guard and Replay pipeline.

IssuePilot and ReproLab

Plans issues behind explicit apply and packages Docker-isolated bug reproductions.

The project is not just a demo UI. It includes packaging, migrations, security tests, public documentation, release automation, and clean-install verification.

04 / Engineering

Shipping the platform mattered as much as implementing it.

Cross-platform CI

Python 3.11 through 3.13 on Windows, Linux, and macOS, plus Linux Docker smoke tests.

Database evolution

Alembic migrations, automatic startup migration, backup, restore, and retention cleanup.

Trusted publishing

PyPI releases use GitHub OIDC, so no long-lived publishing token is stored.

Editor integration

A public VS Code extension installs the runtime, configures workspaces, and opens Guard and Replay.

06 / Lessons

What this project taught me.

  • Large specifications become manageable when they share contracts and release milestones.
  • Security claims should be narrower than the implementation, never broader.
  • Packaging and first-run experience expose architecture problems early.
  • Documentation is part of the product, especially for local developer tools.
  • A small open-source project benefits more from reliable basics than rushed monetization.
